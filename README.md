# TDA Urban Centrality & Hodge Laplacian — Universidad del Pacífico (UP)

Plataforma Web interactiva para el análisis de redes urbanas mediante **Topología Algebraica Aplicada (TDA)**, complejos simpliciales y el **Laplaciano de Hodge de Orden Superior** ($L_0, L_1, L_2$).

Diseñada especialmente para los estudiantes del curso de TDA en la **Universidad del Pacífico (Lima, Perú)**.

## 🚀 Características
- **Cero Instalación:** Ejecución 100% en la nube a través de navegador web.
- **10 Distritos de Lima Pre-cargados:** Acceso instantáneo a los casos de estudio asignados a cada grupo (Jesús María, Miraflores, Barranco, San Isidro, Lima Cercado, San Borja, Magdalena, Pueblo Libre, Surco y Lince).
- **Independiente de Overpass API:** Las redes distritales están pre-procesadas y validadas con consolidación métrica (< 10m).
- **Visores Cartográficos Interactivos:** Exploración con Folium, mapas base multiespectro y capas $k=0, 1, 2$.
- **Exportación Científica:** Descarga de matrices de Hodge (ZIP) y rankings tabulados (CSV) para el informe de grupo.
